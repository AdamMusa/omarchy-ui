# Component coverage moved to Zui

The built-in catalog is owned, packaged, tested, and documented by the
platform-neutral [Zui framework](https://github.com/AdamMusa/zui).

See the [complete Zui component coverage matrix](https://github.com/AdamMusa/zui/blob/main/docs/component-coverage.md).
Omarchy UI consumes that catalog without maintaining an adapter-local copy.
