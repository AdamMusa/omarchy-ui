# Generated showcase image assets

These project-bound images were created with the built-in OpenAI image-generation tool. The
applications remain pure Ruby; the PNGs are ordinary visual assets loaded through the Ruby `image`
component.

## Electric grand tourer

Saved at `tesla_drive_dashboard/assets/electric-grand-tourer.png`.

Prompt: cinematic photorealistic original premium electric grand tourer on a rain-slick alpine
highway at blue hour; wide landscape framing; graphite, cobalt, cyan, and restrained amber palette;
realistic wet materials; darker edge space for UI; no logos, trademarks, text, UI, watermark, or
border.

The same app also uses `tesla_drive_dashboard/assets/vehicle-status-render.png`, generated as an
original pearl-white unbranded electric sedan in an elevated three-quarter studio view with a clean
light-gray background, realistic materials and shadow, and no text, UI, emblems, logos, or
trademarks. It was created specifically for the center-display vehicle-status panel.

## Anatomical heart geometry

Saved at `cardiac_health_monitor/assets/hra-heart.glb`.

This is the HuBMAP CCF / Human Reference Atlas male heart reference object (`VH_M_Heart.glb`),
retrieved from the HuBMAP CCF Releases repository. It is used under CC BY 4.0 and retains its
anatomical structure metadata. Attribution: HuBMAP CCF / HRA 3D Reference Object Library.

- Library: https://hubmapconsortium.github.io/ccf/pages/ccf-3d-reference-library.html
- Source: https://github.com/hubmapconsortium/ccf-releases/tree/main/v1.2/models
